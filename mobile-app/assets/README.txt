Assets Folder - App Icons and Splash Screens

REQUIRED ASSETS:

1. icon.png (1024x1024 pixels)
   - App icon shown on home screen
   - Should be your app logo/branding

2. adaptive-icon.png (1024x1024 pixels)
   - Android adaptive icon foreground
   - Typically just the logo without background

3. splash.png (2048x2048 pixels)
   - Splash screen shown when app launches
   - Background color set to #10b981 (green) in app.json

4. favicon.png (48x48 pixels)
   - Web favicon if hosting on web

TEMPORARY PLACEHOLDER:
You can use any PNG images as placeholders to get started.
Replace with proper branded assets before publishing to stores.

QUICK OPTION:
- Use the project's logo files from ../src/assets/
- Copy headerLogo.png or pesaLogo.png here
- Rename to icon.png and adaptive-icon.png
- Create a simple splash.png with logo centered

These assets are only needed for production builds.
For APK testing, basic placeholders work fine.
